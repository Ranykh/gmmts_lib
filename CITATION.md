# Citation Guide

## To Cite the Project

If you use GMM-TS in a publication, please use citations in the following format (BibTeX entry for LaTeX):

```tex
@software{gmmts2026,
  title = {GMM-TS: Gating-based Multimodal Time Series Forecasting},
  author = {Kathy Razmadze and Yoli Shavit},
  year = {2026},
  url = {https://github.com/NVIDIA/gmmts_lib},
}
```

## Related Work

GMM-TS builds on [MM-TSFlib](https://github.com/AdityaLab/MM-TSFlib). Please also cite the relevant MM-TSFlib publication if applicable to your work.
